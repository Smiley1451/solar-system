Architectural Deep Dive & Findings

⚡ OpenCL GPU vs. CPU Scalar Baseline (35.4×)

The OpenCL pipeline offloads the $O(N^2)$ all-pairs gravitational acceleration calculation to 24 Intel Execution Units. With hardware vector registers and massive thread dispatch, GPU execution finishes in just 0.564 ms per frame compared to 19.94 ms on scalar CPU.

🧠 Why Global Memory Outperformed Local Memory

On integrated Intel GPUs, the CPU and GPU share physical system RAM via Unified Memory Architecture (UMA). Streaming positions directly into registers from L3-cached global memory avoids the work-group barrier synchronization and SLM copying latency of nbody_local.cl.

🧵 OpenMP Multi-Core Scaling (2.92×)

Scaling across 8 logical hyper-threads reduced CPU execution time from 17.33 ms down to 5.93 ms, delivering 56.7 FPS. Thread affinity and dynamic chunk scheduling prevent load imbalance during orbital updates.

🚀 SIMD 128-bit SSE Acceleration (+15%)

The CPU inner loop uses SSE vector intrinsics (_mm_rsqrt_ps, _mm_sub_ps, _mm_mul_ps) to compute 4 coordinate dimensions in a single CPU clock cycle, accelerating single-thread throughput from 130.1 to 149.7 M-interactions/sec.
